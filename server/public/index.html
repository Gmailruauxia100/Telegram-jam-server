Синхронизация аудиосообщений Telegram для двух человек. Музыка остаётся в Telegram, а сервер передаёт только команды плеера.

Без аудио Сервер не получает, не хранит и не передаёт треки или звук звонков.
Только по согласию Сессия начинается после явного приглашения и принятия обоими участниками.
Self-hosted Сервер можно поднять самостоятельно. Комнаты хранятся только в памяти.

Этот сайт обслуживает сервер синхронизации. WebSocket-подключение плагина находится на /jam.
