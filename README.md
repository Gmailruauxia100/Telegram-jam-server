# Telegram Jam

**Русский** · [English](README.en.md)

Совместное прослушивание музыки в Telegram, как Jam в Spotify. Два человека в личном чате слышат один и тот же трек: пауза, перемотка и позиция синхронизируются в обычном плеере Telegram.

Telegram Jam — это плагин для [exteraGram](https://exteragram.app) и небольшой сервер синхронизации, который можно поднять у себя.

## Как это работает

- Треки — обычные аудиосообщения Telegram. Если хост включает трек, которого у гостя ещё нет (из профиля или другого чата), плагин отправляет копию в Jam-чат. После завершения Jam копии удаляются (это можно отключить).
- Сервер передаёт только состояние комнаты: какой трек, играет или пауза, позиция, номер ревизии. Аудио, звонки, переписку и данные аккаунта Telegram он не получает. Комнаты хранятся только в памяти и исчезают после завершения Jam.
- Воспроизведение стартует по общим часам сервера, поэтому у обоих трек начинается одновременно.

## Возможности

- Jam запускается из меню чата, приглашение — команда, которую достаточно нажать и отправить.
- Можно включать любой трек: из Jam-чата, из музыки в профиле или из другого чата.
- Роли хоста и гостя. Хост может разрешить гостю управлять плеером.
- Панель во встроенном браузере Telegram: перемотка, пауза, ±10 секунд, участники, переключатель управления для гостя, выход или завершение Jam.
- В код приглашения зашит адрес сервера хоста, поэтому гость подключается к нужному серверу без настройки.
- Проверка обновлений: сервер сообщает последнюю и минимальную версию плагина, устаревший плагин показывает окно со ссылкой на канал.
- Русский и английский интерфейс, по языку Telegram.

## Установка

1. Возьми `telegram_jam.plugin` в канале [@shit_plugins](https://t.me/shit_plugins) (или в папке `plugin/` этого репозитория).
2. Нажми на файл в exteraGram и установи. Плагин нужен обоим участникам.
3. Сервер по умолчанию — `wss://jam.ltyt.me/jam`. Чтобы использовать свой, поменяй **Адрес Jam-сервера** в настройках плагина (см. [свой сервер](docs/self-hosting.md)).

## Как пользоваться

1. Открой личный чат и выбери **Запустить Jam** в меню чата (или отправь `!startjam`).
2. Собеседник нажимает на команду `!acceptjam <код>` в приглашении, копирует и отправляет её.
3. Включай любой трек. Он запустится у обоих, как только появится у собеседника.
4. **Панель Jam** в меню чата: перемотка, пауза, кто управляет плеером, выход и завершение Jam.

Команды (префикс `!` меняется в настройках):

| Команда | Что делает |
|---|---|
| `!startjam` | Создать Jam и отправить приглашение |
| `!acceptjam <код>` | Присоединиться к Jam; сервер берётся из кода |
| `!declinejam` | Отклонить приглашение |
| `!jamstatus` | Показать роль, режим управления и сервер |
| `!leavejam` | Выйти; если выходит хост, хостом становится гость |
| `!endjam` | Завершить Jam для обоих (только хост) |

## Настройки

| Настройка | По умолчанию | Описание |
|---|---|---|
| Адрес Jam-сервера | `wss://jam.ltyt.me/jam` | Используется, когда ты создаёшь Jam. Гость берёт сервер хоста из приглашения. |
| Управление по умолчанию | Только хост | Может ли гость управлять плеером в новом Jam. |
| Удалять копии треков после Jam | Вкл. | Удаляет копии треков и служебные сообщения, которые отправил плагин. |
| Порт панели | любой свободный | Постоянный локальный порт панели, например `8765`. Если он занят, панель откроется на другом. |

## Структура репозитория

- `plugin/` — плагин для exteraGram.
- `server/` — WebSocket-сервер на Node.js (`npm test` запускает тесты).
- `deploy/` — примеры для Nginx, Caddy и systemd.
- `docs/` — [протокол](docs/protocol.md), [свой сервер](docs/self-hosting.md), [приватность](docs/privacy.md).

## Разработка

```bash
cd server
npm install
npm test
```

Плагин — один Python-файл для движка плагинов exteraGram. Ему нужен `websocket-client`, движок ставит его сам из `__requirements__`.
