# Telegram Jam

**Русский** · [English](README.en.md)

Совместное прослушивание музыки в Telegram, как Jam в Spotify. До 5 человек слушают один и тот же трек: пауза, перемотка и позиция синхронизируются в обычном плеере Telegram.

Telegram Jam — это плагин для [exteraGram](https://exteragram.app) и небольшой сервер синхронизации, который можно поднять у себя.

## Как это работает

- Лобби создаёт один человек — **создатель**. Каждого гостя он приглашает в их личном чате, и треки ходят именно через эти чаты: если у кого-то трека нет, плагин создателя отправляет ему копию. После завершения Jam копии удаляются (это можно отключить).
- **Хост** управляет плеером, кикает и передаёт роль хоста. Сначала хост — создатель, роль можно отдать любому.
- Если хост вышел или пропал из сети дольше чем на 15 секунд, хостом становится другой участник в сети. Если выходит создатель, лобби продолжается: роль создателя (приглашать и раздавать треки) переходит к хосту. Лобби закрывается, только когда в нём никого не осталось или кто-то нажал «Завершить Jam».
- При обрыве связи плагин сам переподключается (до 90 секунд) и возвращается в то же лобби. Если Telegram вылетел или его закрыли, после запуска плагин тоже вернётся в лобби, пока оно живо (участник без связи ждёт 2 минуты, потом выбывает).
- Панель открывается внутри Telegram, как мини-приложение.
- Сервер передаёт только состояние комнаты: участники, какой трек, играет или пауза, позиция. Аудио, звонки, переписку и данные аккаунта Telegram он не получает. Комнаты хранятся только в памяти и исчезают после завершения Jam.
- Воспроизведение стартует по общим часам сервера, поэтому у обоих трек начинается одновременно.

## Возможности

- Лобби до 5 человек на публичном сервере. На своём сервере размер задаёт `MAX_PARTICIPANTS` в `server/.env` (2–50), см. [«Сколько человек в лобби»](docs/self-hosting.md#сколько-человек-в-лобби).
- Jam запускается из меню чата; «Пригласить в Jam» добавляет ещё людей. Код приглашения одноразовый и действует 5 минут.
- Все видят, кто вошёл и вышел. Хост может передать роль хоста, кикнуть участника и убрать его из чёрного списка.
- Можно включать любой трек: из Jam-чата, из музыки в профиле или из другого чата.
- Хост может разрешить всем управлять плеером.
- Панель прямо внутри Telegram: перемотка, пауза, ±10 секунд, участники, чёрный список. По желанию — вкладка «🎵 Jam» среди папок чатов.
- В код приглашения зашиты сервер, код комнаты и одноразовый билет, поэтому гость подключается к нужному серверу без настройки.
- Проверка обновлений: плагин при запуске узнаёт о новой версии (можно отключить), а сервер не пускает слишком старые версии.
- Русский и английский интерфейс, по языку Telegram.

## Установка

1. Возьми `telegram_jam.plugin` в канале [@shit_plugins](https://t.me/shit_plugins) (или в папке `plugin/` этого репозитория).
2. Нажми на файл в exteraGram и установи. Плагин нужен обоим участникам.
3. Сервер по умолчанию — `wss://jam.ltyt.me/jam`. Чтобы использовать свой, поменяй **Адрес Jam-сервера** в настройках плагина (см. [свой сервер](docs/self-hosting.md)).

## Как пользоваться

1. Открой личный чат и выбери **Запустить Jam** в меню чата (или отправь `!startjam`).
2. Собеседник нажимает на команду `!acceptjam <код>` в приглашении, копирует и отправляет её. Код действует 5 минут и только один раз.
3. Чтобы позвать ещё людей, открой личный чат с каждым и выбери **Пригласить в Jam**.
4. Включай любой трек. Он запустится у всех, как только появится у каждого (не дольше 20 секунд ожидания).
5. **Панель Jam** в меню чата: перемотка, пауза, участники, передача хоста, кик и чёрный список.

Команды (префикс `!` меняется в настройках):

| Команда | Что делает |
|---|---|
| `!startjam` | Создать лобби и пригласить собеседника |
| `!invitejam` | Пригласить собеседника в своё лобби (только создатель) |
| `!acceptjam <код>` | Войти в лобби; сервер берётся из кода |
| `!declinejam` | Отклонить приглашение |
| `!jamstatus` | Показать роль, участников и сервер |
| `!leavejam` | Выйти; лобби продолжится без тебя |
| `!endjam` | Завершить Jam для всех (хост или создатель) |

## Настройки

| Настройка | По умолчанию | Описание |
|---|---|---|
| Адрес Jam-сервера | `wss://jam.ltyt.me/jam` | Используется, когда ты создаёшь лобби. Гости берут сервер из приглашения. |
| Проверить сервер | — | Подключиться к серверу из настроек и показать пинг, версию, лимит лобби и пустит ли он этот плагин. |
| Управление по умолчанию | Только хост | Могут ли все участники управлять плеером в новом лобби. |
| Удалять копии треков после Jam | Вкл. | Удаляет копии треков и приглашения, которые отправил плагин. |
| Вкладка Jam в папках | Выкл. | Экспериментально: пока ты в Jam, среди папок чатов есть вкладка, открывающая панель. Нужны папки чатов. |
| Порт панели | любой свободный | Постоянный локальный порт панели, например `8765`. Если он занят, панель откроется на другом. |
| Проверять обновления | Вкл. | При запуске узнать, вышла ли новая версия. Только уведомляет. Рядом кнопка «Проверить сейчас». |

## Структура репозитория

- `plugin/` — плагин для exteraGram.
- `server/` — WebSocket-сервер на Node.js (`npm test` запускает тесты).
- `deploy/` — примеры для Nginx, Caddy и systemd.
- `cloud/update-info/` — [функция проверки обновлений](cloud/update-info/README.md) для Yandex Cloud.
- `docs/` — [протокол](docs/protocol.md), [свой сервер](docs/self-hosting.md), [приватность](docs/privacy.md).

## Разработка

```bash
cd server
npm install
npm test
```

Плагин — один Python-файл для движка плагинов exteraGram. Ему нужен `websocket-client`, движок ставит его сам из `__requirements__`.
